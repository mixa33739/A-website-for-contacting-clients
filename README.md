# A-website-for-contacting-clients
Система автоматизированной обратной связи для АНО «Руснэт»

  Данный репозиторий содержит исходный код веб-приложения, разработанного для централизации обработки обращений клиентов. Система предназначена для замены фрагментированных каналов связи (электронная почта, мессенджеры) единым интерфейсом, обеспечивающим структурированное хранение данных, отслеживание статусов заявок и формирование аналитической отчетности.

# Архитектура и функциональные возможности

 1. Приложение построено по классической клиент-серверной схеме с разделением ответственности между фронтендом и бэкендом.
Клиентская часть представляет собой адаптивный веб-интерфейс, корректно отображающийся на устройствах с различным разрешением экрана (от мобильных смартфонов до десктопов). Интерфейс включает публичную зону с базой знаний (типовые решения проблем) и закрытую зону личного кабинета. Пользователи могут регистрироваться, авторизовываться, создавать обращения с привязкой к конкретному веб-ресурсу и отслеживать историю своих заявок.
 2. Серверная часть реализует бизнес-логику, управление сессиями и взаимодействие с базой данных. API обеспечивает обработку запросов, валидацию данных и защиту маршрутов. Система поддерживает ролевую модель доступа:
1)Пользователь: создание заявок, просмотр статусов, доступ к справочным материалам.
2)Администратор: управление входящими обращениями, изменение статусов (Новое, В работе, Решено, Закрыто), просмотр полной статистики.
  3. База данных спроектирована в соответствии с требованиями третьей нормальной формы (3НФ). Схема включает шесть взаимосвязанных таблиц, обеспечивающих ссылочную целостность и исключающих дублирование данных. Реализованы механизмы каскадного удаления и журналирования действий пользователей для обеспечения безопасности и аудита.

# Технологический стек
Frontend: HTML5, CSS3, JavaScript (ES6+). 

Backend: Python, Flask. 

Database: MySQL (InnoDB).

Инструменты: DBeaver (администрирование БД), Git (контроль версий), Thunder Client (тестирование API).
# Структура репозитория
Проект организован следующим образом:
RusnetFeedbackSite/ — файлы клиентской части приложения (HTML-страницы, таблицы стилей, скрипты логики).
rusnet_backend/ — серверная часть на Python, включая конфигурацию, модели SQLAlchemy, маршруты API и точку входа.
1.env — шаблон файла переменных окружения для настройки подключения к базе данных и секретных ключей.
# Требования к окружению
Для локального запуска и разработки необходимы:
1. Интерпретатор Python версии 3.8 или выше.

2. Сервер базы данных MySQL версии 5.7 или выше (либо MariaDB).

# Запуск и настройка
Процесс развертывания системы состоит из подготовки базы данных и запуска серверного приложения.

1/ Сначала необходимо создать базу данных в MySQL. Скрипт для создания схемы и таблиц (rusnet_feedback)

2/ Далее следует настроить переменные окружения. Для этого нужно создать файл .env в корневой директории бэкенда на основе предоставленного шаблона 1.env, указав актуальные данные для подключения к MySQL (хост, порт, имя пользователя, пароль) и секретные ключи для генерации JWT-токенов.

3/ После настройки окружения устанавливаются зависимости Python и запускается сервер. По умолчанию приложение начинает прослушивать порт 5000 на локальном хосте. Клиентская часть (файлы из папки RusnetFeedbackSite) открывается в браузере напрямую или через любой статический веб-сервер, при этом в коде скриптов (api.js) должен быть указан корректный адрес работающего API.

# Тестирование
В ходе разработки проводилось функциональное тестирование компонентов. Проверка API осуществлялась с помощью расширения Thunder Client, что позволило изолированно протестировать маршруты авторизации, создания обращений и получения списков данных. Клиентская часть проверялась на кроссбраузерность (Chrome, Firefox) и корректность работы механизмов валидации форм. Время отклика интерфейса при локальном тестировании составило 15–28 мс.
